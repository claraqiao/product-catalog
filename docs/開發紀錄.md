# V1.2 開發紀錄

## 階段 1 — iPad／手機管理介面與雲端骨架
- 依 V1.2 重建響應式 Web 管理介面，停止沿用 Windows Tkinter 作為正式管理端。
- 建立管理端頁面：登入、總覽、產品管理、分類、照片、CSV、發布、備份、設定。
- 建立 Worker API 及 D1 schema；登入採 PBKDF2-SHA256 雜湊驗證、簽章工作階段與基本失敗鎖定。
- 完成產品新增／編輯、分類新增、CSV 乾跑／匯入／匯出及多張照片上傳初稿；原圖私有、展示圖僅在產品上架後公開。
- 完成發布快照檢查、管理端預覽、人工確認發布；公開型錄只讀最後已確認快照，草稿修改不會提前覆蓋公開版本。
- 狀態：原始碼已建立；尚未部署、尚未接上真實雲端帳號與照片儲存，未完成安全驗收。

## 下一階段
1. 完成登入復原流程、Origin／CSRF 安全審查及第三方安全測試。
2. 完成照片排序、替換、刪除、重試與圖片品質實測。
3. 完成遠端正式部署、公開版本回復及發布失敗補償。
4. 完成備份／還原及免費額度保護。

## 階段 2 — 照片管理操作補強
- 新增管理者登入後讀取指定產品照片清單的 API；照片預覽透過受保護 API 提供，不直接公開未發布照片。
- 新增照片順序更新 API；會檢查傳入 ID 是否與資料庫現有照片完全一致，避免舊畫面覆蓋新資料；第一張自動標記封面。
- 新增照片刪除 API；刪除資料列後同步清除 R2 原圖、展示圖與縮圖，並重新整理排序及封面。
- iPad／手機管理頁新增照片縮圖、上移／下移、刪除確認；原有多選上傳及處理進度保留。
- 狀態：程式碼與靜態語法檢查完成；尚需在實際 Cloudflare D1/R2 環境測試 API、iPad Safari 實機操作與失敗情境。

## 階段 3 — 完整備份下載與備份檢查
- 新增受管理者工作階段保護的完整備份 API：匯出產品、分類、照片關聯、發布版本、公開快照、操作紀錄、設定，以及 R2 原圖／展示圖／縮圖內容。
- 備份包採版本化 JSON 格式；不包含管理密碼、Token、登入工作階段或登入限流狀態。
- 新增 iPad／手機管理介面備份下載；下載前由後端收集資料與圖片，並回報備份檔大小。
- 新增備份檔完整性檢查：檢查格式版本、必要資料表、照片路徑白名單、圖片 MIME 類型及照片資料筆數。
- 安全限制：單次備份的照片原始內容總量目前限制 18 MiB，超出會明確停止並提示；這是目前實作限制，不代表可支援任意大小的完整照片庫。
- **尚未開放覆蓋還原**：目前僅能檢查備份檔。因為尚未完成還原前自動備份、跨資料表原子切換、失敗回復及實際還原驗收，先不提供會覆蓋現有資料的按鈕，避免資料遺失。
- 狀態：程式碼與靜態語法檢查完成；完整備份需在 Cloudflare D1/R2 真實環境驗證，未完成實際下載與內容比對前不宣稱通過驗收。

## 下一階段
1. 完成安全的還原流程：還原前備份、暫存匯入、原子切換、失敗回復與實際還原測試。
2. 照片逐檔重試與替換流程、圖片品質實測。
3. 登入復原流程、Origin／CSRF 安全審查及第三方安全測試。
4. 免費額度監測／停止閘門、遠端部署、2,000 款壓力測試及 T-001–T-040 驗收。


## 階段三補強（2026-11-20）
- 備份檢查改為逐筆核對每張產品照片的原圖、展示圖與縮圖物件鍵，並檢查重複鍵與 Base64 格式；不再錯把每張照片的三個檔案當成一個檔案。
- 備份檢查 API 加上 32 MiB 請求大小上限，避免超大 JSON 被無限制讀取。
- 照片上傳改為逐張送出，失敗項目保留在頁面中，只重試失敗照片；每張照片使用上傳識別碼及資料庫紀錄，網路中斷後以相同識別碼重送可避免重複新增。
- 新增 `photo_upload_requests` 資料表，備份亦包含此表。
- 尚未進行 Cloudflare 真實 D1/R2 整合測試；正式還原仍未開放。
