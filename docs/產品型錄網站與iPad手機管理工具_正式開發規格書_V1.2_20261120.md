### 1.3 延續 V1.1 的公開存取定義

1. 公開型錄任何人只要知道網址即可瀏覽已上架產品，不要求帳號、登入、驗證碼或訪客密碼。
2. 管理端與公開型錄必須分離。**管理者登入不等於廠商訪客登入**；訪客仍維持免登入。
3. 公開輸出不得包含草稿、下架產品、管理端 API 機密、管理帳號資料、資料庫備份、原始大圖（除非明確作為公開展示圖）、內部備註、Token 或供應商專屬價格（除非日後明確選擇公開）。
4. 公開網址不是保密措施；內容可被轉傳、截圖、下載、快取或第三方保存。下架只能從新公開版本移除，不能收回已流通內容。
5. 搜尋引擎是否收錄仍為獨立待決事項；建議初始採 `noindex`，但這不是存取控制。

## 2. V1.2 系統架構（正式設計方向）

```text
使用者 iPad（主要）／iPhone（完整支援）
        │ Safari／手機瀏覽器
        ▼
受保護的 Web 管理介面（繁體中文、管理者登入）
        │
        ├── 產品／分類／規格管理 API
        ├── 草稿、版本、操作紀錄與發布流程
        ├── 圖片處理：縮圖、WebP、EXIF 清理
        └── 備份／還原／CSV 匯入匯出
                 │
        ┌────────┴─────────┐
        ▼                  ▼
雲端資料庫          雲端物件儲存（原圖／展示圖）
        │                  │
        └────────┬─────────┘
                 ▼
       私有預覽（登入後可檢視草稿）
                 │ 管理者按「確認發布」
                 ▼
          公開靜態型錄／公開圖片
                 │
                 ▼
       廠商手機／平板／電腦（免登入）
```

### 2.1 技術提案與成本閘門

- **前端管理介面**：響應式 Web App，以 iPad Safari 為主要版型，iPhone Safari 為必要支援；可評估 PWA「加入主畫面」，但不得要求安裝 App Store 原生 App。
- **後端 API**：採可在免費方案內運作的受控 API；建議先評估 Cloudflare Workers。
- **資料庫**：建議先評估 Cloudflare D1 或同級免費方案；資料表需包含產品、分類、圖片、版本、管理者及操作紀錄。
- **圖片儲存**：建議先評估 Cloudflare R2 Standard 儲存；原圖、展示圖與縮圖分開管理，公開圖與私有原圖採不同存取權限。
- **公開網站**：保留靜態型錄與免登入瀏覽的原則；可由 Pages 或等價靜態託管服務發布。
- **圖片處理**：可在瀏覽器上傳前先縮小，並由後端完成格式、尺寸、EXIF 與內容檢查；原圖不可被覆寫。
- **費用保護**：初期只允許免費方案；不得自行升級 Workers Paid 或其他付費層級。必須設定用量監測、額度警告及超額停止策略。任何可能產生費用的變更，先取得使用者明確同意。

**免費額度風險（查核日 2026-11-20）**：Cloudflare 官方資料顯示，Workers Free 有每日請求與 CPU 限制；D1 Free 有資料庫容量及每日讀寫列數限制；R2 Standard 免費額度包含每月 10 GB-month 儲存、Class A 及 Class B 操作額度。超過免費額度可能產生費用或服務操作失敗，故 NT$0/月只能作為「符合免費額度時的目標」，不是永久保證。正式建置前必須依實際照片容量、流量與操作量再次估算，並設定用量上限／警告。不得因使用者未提供付款同意而自動轉付費方案。

### 2.2 服務相依性

1. 首次設定需要建立並由使用者本人授權雲端平台帳號；不得代替使用者登入或取得未授權憑證。
2. 日常管理只需 iPad／手機與網路，不需使用命令列、Node.js、Python、Wrangler 或 Windows。
3. 管理服務需要網路連線；無網路時可瀏覽已載入的公開頁面快取，但**不承諾離線新增、修改、上傳或發布**。
4. 管理者帳號復原方式、登入驗證及備援聯絡方式須在首次設定時確認，不可把管理端做成公開可寫入。

## 3. iPad／手機管理介面規格

### 3.1 裝置與版面要求

- iPad 橫向與直向皆可操作；主要管理體驗以 iPad 為優先。
- iPhone／一般手機需能完成所有核心管理工作，不得只有唯讀或僅能瀏覽。
- 介面繁體中文；按鈕、欄位、錯誤提示及確認訊息均使用繁體中文。
- 觸控按鈕與操作目標需適合手指操作；避免依賴滑鼠 hover、右鍵或拖曳才能完成的流程。
- 表單在手機上採單欄；iPad 可採雙欄或分區，但不得讓重要按鈕被遮住。
- 上傳、儲存、匯入、發布與備份均顯示進度、成功／失敗結果及可理解的錯誤原因。

### 3.2 功能模組

- **ADM-001 儀表板**：全部／上架／草稿／下架款數、待發布變更數、最近發布時間、備份狀態、圖片儲存量及免費額度預估。
- **ADM-002 產品列表**：SKU、名稱、分類、關鍵字、狀態搜尋；排序、分頁；支援批次上下架、分類與封存。2,000 款資料仍須可操作。
- **ADM-003 產品編輯**：建立、修改、複製產品；規格、系列、關鍵字、主圖與照片排序；儲存後標記為待發布。
- **ADM-004 照片管理**：從 iPad／手機相簿、相機或「檔案」選取多張圖片；支援單張替換、排序、刪除展示關聯、旋轉、預覽及重新處理；原始檔不可被展示圖流程覆寫。
- **ADM-005 批次匯入／匯出**：支援 UTF-8 CSV（含 BOM）；上傳前乾跑，顯示新增／更新／錯誤筆數；重複 SKU 不得靜默覆寫；匯出可下載到 iPad／手機檔案位置。
- **ADM-006 分類管理**：大分類、小分類／系列、排序；刪除前確認關聯產品如何處理。
- **ADM-007 私有草稿預覽**：產生與正式站一致的頁面與圖片效果；只有已登入管理者能檢視，不得讓未登入訪客讀取草稿。
- **ADM-008 發布管理**：顯示待發布變更、錯誤檢查、預覽、人工確認、發布進度、部署結果與公開網址。發布按鈕需二次確認。
- **ADM-009 備份與還原**：可下載包含資料、原圖、展示圖、設定及版本資訊的備份包；不包含登入密碼、Token 或其他憑證。還原前顯示備份日期、產品數、照片數及覆蓋範圍，並先建立目前資料備份。
- **ADM-010 系統設定**：網站名稱、LOGO、主色、聯絡方式、project name、圖片處理選項、搜尋引擎 noindex 設定、用量警告門檻。
- **ADM-011 管理者登入與安全**：管理端必須驗證管理者身分；工作階段逾時、安全登出、登入失敗節流；不得將管理密碼或 Token 寫入前端程式、公開網站、CSV 或一般備份。

### 3.3 iPad／手機照片上傳行為

1. 使用者可從相簿或「檔案」多選照片；若 iOS 版本／瀏覽器不支援資料夾整批選取，須提供多選檔案或依 SKU 分批上傳的替代流程，不得要求使用者改用電腦。
2. 上傳前顯示已選檔名、縮圖、檔案大小、格式及可能的重複項目；使用者確認後才開始上傳。
3. 上傳過程顯示整體與單檔進度；網路中斷後可重試失敗項目，不可造成已成功項目重複關聯。
4. 允許 JPG、PNG、WebP；不支援或損毀檔案須明確回報。
5. 自動依 EXIF 正確旋轉，公開版本移除非必要 EXIF（含位置資訊）；原圖完整保存。
6. 原圖上傳後可依 SKU／使用者指定產品建立關聯；不得只依檔名猜測並直接覆寫既有照片。
7. 每款產品預設最多 5 張公開展示照片 + 1 張列表縮圖；超出提示，不默默刪除。此為沿用 V1.1 技術預設，仍可在後續確認後調整。

## 4. 資料模型與安全邊界

延續 V1.1 的 `products`、`categories`、`product_images`、`publish_revisions`、`audit_log`、`app_settings` 等資料概念；另增加管理者與登入工作階段所需資料。所有管理資料只能經過受保護 API 存取。

| 資料 | 儲存位置 | 公開？ | 規則 |
|---|---|---|---|
| 產品 SKU、名稱、分類、公開規格、關鍵字 | 雲端資料庫 | 上架後公開 | 僅 `active` 輸出 |
| 草稿與下架產品 | 雲端資料庫 | 否 | 不得由公開索引查出 |
| 內部備註 | 雲端資料庫 | 否 | 永遠不得進入公開 JSON／HTML |
| 原始照片 | 私有物件儲存 | 否 | 需管理者授權才可讀取 |
| 展示圖／縮圖 | 物件儲存或公開靜態資源 | 上架後公開 | 使用不可猜測或內容雜湊檔名；換圖後快取失效正確 |
| 管理者憑證／工作階段 | 安全驗證服務 | 否 | 不輸出到前端靜態檔、CSV 或備份 |
| 發布版本與操作紀錄 | 雲端資料庫 | 否 | 保留版本差異與操作時間 |

### 4.1 管理者與訪客的權限分離

- 公開訪客只可讀取已發布型錄與公開圖片，不需要登入。
- 管理者可登入後新增、修改、上傳、預覽、發布及備份。
- 草稿 API、原圖 API、備份 API、匯出 API 必須驗證管理者工作階段。
- 不得把「知道管理網址」當成安全措施；管理端必須有身分驗證。
- 第一版以單一主要管理者為基線；若要新增多位管理者、角色或多人協作，列為後續需求，不自行加入。

## 5. 草稿、預覽、發布與回復

### 5.1 發布狀態機

`管理者修改資料` → `儲存草稿` → `建立發布快照` → `驗證` → `私有預覽` → `管理者人工確認` → `發布公開版本` → `線上抽樣檢查` → `記錄發布成功`

1. 編輯儲存不會直接更新公開型錄。
2. 發布檢查包含 SKU 唯一、必填欄位、上架照片存在、圖片可解碼、內部資料未輸出、檔案數與大小限制、連結有效及權限檢查。
3. 檢查失敗時禁止發布，顯示可定位的問題清單。
4. 管理者必須明確按下「確認發布」，並再次確認本次上架／下架／照片更換清單。
5. 發布期間新編輯的內容必須保留為待發布，不得被誤標為已發布。
6. 成功發布須有平台回應及公開網址抽樣檢查；未完成驗證不得宣稱成功。
7. 遠端公開版本回復與資料庫／照片資料還原為不同操作，需分開說明並留紀錄。

### 5.2 備份與還原

- 每次發布前建立資料庫與照片版本備份或可回復快照。
- 管理者可從 iPad／手機下載備份包至「檔案」或其他指定位置。
- 備份包包含產品、分類、原始照片、展示照片、設定及版本資訊，不含密碼、Token、工作階段憑證。
- 還原前先顯示備份內容與預計覆蓋項目，並自動建立目前資料備份。
- 必須以測試帳戶／測試資料實際完成一次下載與還原驗收；未驗收不得宣稱備份可用。
- 若僅將資料存於雲端而未提供可下載備份，不符合本規格。

## 6. 公開型錄網站（延續 V1.1）

以下需求不因管理端改為 iPad／手機而降低：

- 首頁、全部產品列表、SKU／名稱／關鍵字搜尋、分類篩選、產品詳細頁、新品頁、聯絡資訊及響應式版面。
- 電腦寬度 ≥ 1024 CSS px 預設 3 欄，提供 2／3 欄切換；手機 < 768 px 預設 2 欄；圖片完整呈現不變形。
- 點擊產品封面開啟燈箱；顯示 SKU 與第 n／total 張；上一張／下一張、手機左右滑、桌面方向鍵、Esc、關閉按鈕；不重新整理整頁。
- 燈箱只在同一產品照片間切換，預設不跨產品自動跳轉。
- 列表先載入縮圖；放大時載入展示圖；只預載相鄰照片，不預載整站 2,000 款高清圖。
- 直接開啟產品深層連結必須正常顯示；不存在或下架 SKU 顯示「查無此產品」，不洩露內部資料。

## 7. 圖片資源與用量控制

沿用 V1.1 每款預設 5 張展示圖 + 1 張縮圖、展示圖長邊建議 1,600 px、縮圖長邊建議 480 px、WebP 品質約 80 的起始提案；需用實際商品照片校正畫質與容量。

- 公開型錄清單只能載入縮圖；放大才載入展示圖。
- 原圖不得因壓縮或重新處理而覆寫。
- 每張照片以穩定識別碼與內容雜湊命名，避免換圖後顯示舊快取。
- 需顯示已用儲存量、照片數、API 用量及平台免費額度的估算；額度資料以平台官方儀表板為準。
- 設定警告門檻；達到警告門檻時提示管理者整理照片或評估容量；接近免費上限時暫停新增／發布，直到管理者處理。
- 不得自動升級付費方案、增加付費儲存或購買網域。

## 8. 效能與正式驗收

### 8.1 照片切換

1. 已預載／快取相鄰圖：同一輪至少 30 次切換，P95 ≤ 300 毫秒。
2. 未快取圖片：以 Chrome DevTools 模擬 10 Mbps 下行、150 ms RTT、無丟包，樣本圖片適當壓縮後 P95 ≤ 2 秒；未達標需提供量測紀錄並優化。
3. 切換若不能立即完成，100 毫秒內顯示非空白過渡狀態；保留前圖或顯示載入標記。
4. 不可預載整個 2,000 款產品目錄的高清圖片。
5. 至少使用 2,000 款測試資料及代表性多圖商品，在 iPad Safari、iPhone Safari、Android Chrome 及桌面 Chrome／Edge 測試。

### 8.2 管理端驗收

- 測試上傳中斷、重試、重複檔案、錯誤格式、登入逾時、權限不足、發布失敗及免費額度用盡等情境。
