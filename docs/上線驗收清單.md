# 產品型錄上線驗收清單（iPad／iPhone）

本清單用於驗證真正可使用的網站；GitHub 程式已提交 **不代表** Cloudflare 已部署。

## 第一階段：可用版本（少量照片試營運）
- [ ] Cloudflare Worker 的正式 HTTPS 網址可以開啟，顯示產品型錄
- [ ] `/api/health` 回傳 `ok: true`，D1 資料表已建立
- [ ] 管理員能登入 `/admin/`；密碼與工作階段秘密已安全設定
- [ ] 在 iPad 新增分類與一件測試商品，設定商品編號及名稱
- [ ] 上傳兩張測試照片，確認預覽、封面、照片順序正確
- [ ] 商品先存草稿，不應出現在客人的公開頁面
- [ ] 按發布後，使用另一支手機或無痕瀏覽器確認公開商品及照片
- [ ] 客人可以搜尋、切換分類、放大照片、分享商品連結
- [ ] 公開網址不能看到未發布商品或管理介面資料
- [ ] 手機瀏覽和 LINE 開啟正常，無破圖
- [ ] 備份測試商品與照片，確認下載檔案已實際存入 iPad「檔案」
- [ ] 完成以上項目，才可標記為「少量照片試營運通過」

## 第二階段：正式版（每季約 800 張照片）
- [ ] 確認 R2 或其他儲存方案容量、費用及寫入權限
- [ ] 實際匯入接近 800 張照片，確認容量與操作效能
- [ ] 確認每張照片有縮圖與展示圖，並保留可還原的原始檔
- [ ] 完成大量照片的整批備份、驗證、完整還原演練
- [ ] 在 iPad、iPhone 上實測新增、編輯、發布、搜尋及照片切換
- [ ] 完成還原前安全備份、資料庫遷移與故障復原驗證
- [ ] 完成以上項目，才可標記為「正式版驗收通過」

## 唯讀網站自動檢查
在有 Node.js 的測試環境執行：
```sh
node tools/check_live_site.mjs https://實際的網站網址
```
會檢查首頁、後台頁面、公開商品 JSON、設定 JSON、主要程式及樣式、資料庫健康狀態、未登入時的管理 API 權限，以及最多五件已發布商品的部分照片。**不會**登入、上傳、刪除、發布或修改正式資料。

## 已知限制
- 尚未取得並驗證正式 Cloudflare 網址，不可宣稱已上線
- D1 試用照片儲存不保證可放 800 張照片
- 單檔完整備份有 18 MiB 上限；目前沒有完整覆蓋還原功能
- 在備份還原正式通過前，必須自行保留 iPad／手機上的相機原始照片
